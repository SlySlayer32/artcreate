

Project Name: WorldNarrator

Purpose:
WorldNarrator is an AI system that converts printed text from camera images into contextual narrated audio experiences using multimodal AI models and expressive speech synthesis.

Core pipeline:
Camera Image → Image Processing → Document Intelligence → Narration Director → Voice Generation → Streaming Audio.

The project must be structured using modern best practices including modular services, clear separation of concerns, and scalability.

SERVICE RESPONSIBILITIES

api-gateway
Handles authentication, routing, rate limiting, and API entry.

image-processor
Handles image preprocessing including cropping, rotation, contrast enhancement, and noise reduction.

document-intelligence
Uses multimodal models to extract structured information from images including text segments, dialogue, and layout.

narration-director
Transforms structured text into narration instructions including tone, pacing, voice assignments, and emotional direction.

voice-synthesis
Interfaces with speech synthesis APIs to convert narration segments into audio files.

audio-streamer
Streams generated audio to the client with low latency.

DATA FLOW

User captures image → image uploaded → preprocessing → document analysis → narration strategy → voice generation → streaming audio.

# Why This Prompt Works

It forces the AI to:

• create **real architecture instead of random files**
• separate services cleanly
• include infrastructure from the start
• generate reusable AI pipelines

That avoids the most common problem with AI-generated projects: **monolithic spaghetti code**.

---

# One Important Strategic Advice

For your **first working prototype**, do **not build all services immediately**.

Collapse them temporarily into:

```
api
vision
narration
tts
```

Get the pipeline working first.

Then split into microservices once the logic stabilizes.

That saves weeks of unnecessary engineering.

---

A curious observation about your project: the **Narration Director** service will likely become the most valuable component. Most teams can build OCR pipelines, but very few build **AI systems that understand storytelling structure and direct audio performance**. That piece is where the intellectual leverage lives.
